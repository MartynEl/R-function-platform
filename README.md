# R-Function Recommendation Platform (PoC)

Промышленный прототип отказоустойчивой рекомендательной системы с жесткими ограничениями на базе гибридной модели Factorization Machines и R-функций Рвачёва.

### 🚀 Быстрый запуск (Релиз v2.0.0-pro)

1. **Установка зависимостей в локальное окружение** (необходимо для холодного старта базы):
   ```bash
   pip install -r requirements.txt
   ```

2. **Первичная инициализация и генерация данных**:
   Скрипт создаст схемы таблиц в ClickHouse и локальный индексированный файл базы данных Milvus Lite:
   ```bash
   python init_data/generate_data.py
   ```

3. **Сборка и запуск контейнеров**:
   ```bash
   docker-compose up -d --build
   ```

4. **Проверка работы**:
   * Интерактивная документация Swagger: `http://127.0.0`
   * Логи симулятора трафика (Smart Feed): `docker logs -f r_traffic_sim`


### Мониторинг и Проверка
* **Интерактивная документация API:** Откройте в браузере `http://127.0.0`
* **Умная лента (Этап А + Б):** Проверьте метод `GET /smart-feed` для `user_id=777` при возрасте `30` и `10` лет, чтобы увидеть динамическую блокировку R-функции в действии.
* **Логи трафика:** `docker logs -f r_traffic_sim`
