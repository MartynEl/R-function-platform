# R-Function Recommendation Platform (PoC)

Промышленный прототип отказоустойчивой рекомендательной системы с жесткими ограничениями на базе гибридной модели Factorization Machines и R-функций Рвачёва.

### Стек технологий
* **Язык:** Python 3.10 (PyTorch, FastAPI, Uvicorn, Pydantic)
* **Аналитическое хранилище (Сырые логи):** ClickHouse (MergeTree движок)
* **Векторная БД (Метаданные и эмбеддинги):** PostgreSQL + `pgvector`
* **Оркестрация:** Docker / Docker Compose / Cron

### Быстрый старт (Развертывание в один клик)

1. Убедитесь, что у вас установлен Docker и настроен файл `.env` в корне проекта.
2. Поднимите всю инфраструктуру, сервисы и планировщик обучения:
   ```bash
   docker-compose up --build -d && docker image prune -f
   ```
3. Инициализируйте базы данных и залейте 50 000 синтетических поведенческих логов (имитирующих детей, подростков, взрослых и аномалии доступа):
   ```bash
   docker exec -it r_traffic_sim python init_data/generate_data.py
   ```
4. Запустите принудительный расчет скрытых факторов (ночной цикл обучения) для синхронизации весов в `pgvector`:
   ```bash
   docker exec -it r_offline_worker python train_service/offline_train.py
   ```

### Мониторинг и Проверка
* **Интерактивная документация API:** Откройте в браузере `http://127.0.0`
* **Умная лента (Этап А + Б):** Проверьте метод `GET /smart-feed` для `user_id=777` при возрасте `30` и `10` лет, чтобы увидеть динамическую блокировку R-функции в действии.
* **Логи трафика:** `docker logs -f r_traffic_sim`
